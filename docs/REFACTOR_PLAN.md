## Stages

1. **Audit — DONE.** Collected source files, line counts, tests, cycles, baselines, and current Git/Docker state. Completed report: `docs/CODEBASE_AUDIT.md`.
2. **Plan approval — DONE.** The user approved full refactoring, performed in stages without commits.
3. **Safe test harness — IN PROGRESS.** Add cleanup/isolation for live E2E; verify sign-in, catalog, create/upload/edit, custom properties, outfits, and settings. Do not call real Gemini.
4. **Shared contracts and cycles — DONE.** Extracted `garment.ts`, `vocabulary.ts`, `outfit-decision.ts`, `outfit-style.ts`, `outfit-text.ts`; outfit/belt and full tests pass, with zero graph cycles.
5. **Web garments — IN PROGRESS.** Form, details, metadata, processing, outfits, and inline/custom-property components extracted; mocked desktop/mobile Playwright 2/2 PASS and custom-field selection component tests pass. Continue reviewing remaining modules.
6. **Web catalog/navigation — IN PROGRESS.** Dashboard (`dashboard.tsx`) separated from catalog; card/catalog queries, context/provider, and shell/router remain. Preserve filters, selector, ordering, and scrolling.
7. **Outfits — DONE (module separation); profile — IN PROGRESS.** UI requests/cards/saved views moved to `outfits.tsx`; Gemini payload/output unchanged. Survey and style summary split into `style-survey.tsx` and `style-profile.tsx`; form and typed lint review remain.
8. **Image analysis and bulk upload — IN PROGRESS.** Status, suggestion review, upload batches, and retries; preserve original hash/persistence invariants.
9. **Auth/shared UI/settings — IN PROGRESS.** Landing separated from auth forms; Gemini settings extracted from general settings. Transport/API errors and CSRF/keyboard/accessibility tests remain.
10. **Fastify API routes — DONE.** Auth/profile/wardrobes/garments/custom-properties/images/jobs/outfits endpoints moved into domain modules without SQL migrations. Gemini/session/queue and typed lint review remain separate stages.
11. **Worker/Gemini — IN PROGRESS.** Image/AI handlers, Gemini worker, and dispatcher extracted; bootstrap/shutdown and missing orchestration tests remain.
12. **Remaining shared/configuration — TODO.** Make only justified improvements, adjudicate Knip manually, and avoid global deletion.
13. **ESLint and Prettier debt — TODO.** Fix alongside each module and reduce baselines after each batch; never increase them merely for convenience.
14. **Final regression — TODO.** `pnpm check`, isolated Playwright E2E, API contract verification, UI screenshots, and change/status audit.

## Stage acceptance criteria

- Every batch ends with relevant domain/API/UI tests, typecheck, lint without baseline growth, and `deps:check`.
- Run `pnpm check` after larger changes. E2E requires an isolated environment and guaranteed cleanup.
- No API/database/RLS/job payload/Gemini prompt/model/quota/appearance changes without separate approval.
- Never delete Knip findings automatically; adjudicate each of the 32 findings individually when touched.
- Update `docs/REFACTOR_PROGRESS.md` after every stage; DONE requires actual verification.

## Scope and risk

Planning estimate: approximately **12–18 small batches/PRs**, covering about **25 modules needing real separation**, plus remaining source/test review. Schema changes are excluded. Greatest risks concern data/authorization (`app.ts`), editing/rotation state (`garments.tsx`), job durability (`worker/index.ts`), and appearance (styles). With 82 changed/untracked entries, review and selectively preserve each touched file’s existing diff before editing.
